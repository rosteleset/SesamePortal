# Камеры с агентом SesameDVR

В таблице указаны модели и аппаратные ревизии, для которых подготовлена прошивка
или отдельный модуль агента. Перед выбором прошивки сверьте полное обозначение
модели и ревизию платы. Сходное название камеры не означает, что образы совместимы.

| Модель или семейство | Протокол агента | Что учитывать |
| --- | --- | --- |
| OMNY miniBullet2E-WDS-SDL 28 (Forpost) | LinkAPI | Ревизия S35/M0513. |
| OMNY miniBullet2E-WDS-SDL 36 (Forpost) | LinkAPI | Ревизия S37/M1509. Образ для модели 28 не подходит. |
| OMNY miniBullet5E-WDS-SDL 28 (Forpost) | LinkAPI | Для S37/M0604 проверены видео, запись архива и ONVIF. Для звука в HLS нужен AAC. |
| Secret / Ufanet BR500 | LinkAPI | Для M0602 есть экспериментальная сборка. |
| SVN-R25IP3CM | IPEYE | Образ предназначен для этой модели. |
| SVN / HeroSpeed | IPEYE | Проверена камера семейства FG22XX / FG22X2. Нужна совместимая версия DVR. |
| JVS-CR1 / Iris | Flussonic Agent (Peeklio) | Проверена прошивка на штатной базе 25.04. |
| Камеры на платформе XM530 | Flussonic Agent (Peeklio) | Пакет предназначен для профиля `XM530_80X20_8M`, а не для всех камер на XM530. |
| KENO KN-PVN1BR | UMEye / Fseye | Модуль устанавливается поверх штатного ПО без замены прошивки. |

Для указанных ревизий OMNY работа проверена на отдельных устройствах;
массовая установка не проверялась. У M0604 поддержка физических событий
движения не подтверждена.
